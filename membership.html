Membership · Patreon-backed access

Join the member archive.

Membership supports Grok Archive Hub's records-first work and unlocks the protected member portal when Patreon confirms an active entitled membership. If entitlement cannot be verified, protected routes fail closed.

Public proof rule

Public evidence stays public.

Public evidence remains open. No membership tier removes, hides, or paywalls the existing public evidence archive, SEO stories, source pages, search routes, dispatches, methodology pages, or correction paths. Membership funds the work around the archive.

What membership does not do

  • It does not hide public proof.
  • It does not create private accusations.
  • It does not guarantee a source request outcome.
  • It does not provide legal advice.
  • It does not collect payment-card data on this site.
  • It does not store raw OAuth tokens in the browser.
