Required disclaimer: This is a Reading Room review queue, not a public evidence gallery. Items in visual review are not public findings, not identity conclusions, and not proof of conduct.

Review Purpose

This page tracks the lane-level workflow for visual files before any future visual receipt card exists. It does not list individual raw images because no item-level visual card has been reviewed for public use in this task.

Visual Safety Checklist

  • Minors
  • Faces
  • Addresses
  • Phone numbers
  • Email addresses
  • Signatures
  • Private documents
  • Irrelevant personal data
  • Medical/legal-sensitive material
  • Context missing
  • Source path missing

Duplicate / Near-Duplicate Checklist

Exact duplicate

Check whether the same image appears more than once in the batch or another source lane.

Near duplicate

Check crops, thumbnails, alternate exports, screenshots of the same source, and re-saved copies.

Source grouping

Group duplicates before public use so one image does not become multiple unsupported signals.

Source-Path Checklist

  • Vault path preserved.
  • Extraction batch identified.
  • Related archive ID checked.
  • Source record or source lane identified.
  • Date and caption used only if source-supported.
  • No OCR extraction performed in this workflow.

Privacy-Risk Checklist

Any visual containing private personal data, irrelevant personal details, minors, faces, addresses, phone numbers, private email addresses, signatures, medical details, or legal-sensitive material remains out of public pages until a future controlled review decides whether a redacted or non-public handling path is required.

Future Receipt Readiness Checklist

  • Source path confirmed.
  • Batch confirmed.
  • Privacy review passed.
  • Visible content summary drafted.
  • Related archive IDs checked.
  • What-it-shows drafted.
  • What-it-does-not-prove drafted.
  • Open slots listed.
  • Public-safe decision made.
