# Corrections Checklist

Status: REVIEW_DRAFT

- [ ] Every correction request must identify a claim ID from `claim-ledger.json`.
- [ ] Every correction request must identify a source ID from `evidence-manifest.json`.
- [ ] A proposed replacement record must be primary or clearly marked as secondary/context.
- [ ] Direct quotation changes must be reflected in `source-quote-ledger.json`.
- [ ] Any changed claim classification must be reviewed against `legal-risk-review.md`.
- [ ] Any changed narration line must update `narration.md`, `narration.txt`, and `captions.en.vtt`.
- [ ] Any changed visual source must update `scene-plan.json`, `shot-list.md`, and `on-screen-text.json`.
- [ ] Any publication-stage correction must update the future YouTube description and pinned comment before upload.
- [ ] Captions must be retimed after final audio render.
- [ ] No correction may introduce a criminal-conduct allegation unless the cited primary record establishes the procedural posture.
