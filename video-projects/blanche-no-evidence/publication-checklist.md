# Publication Checklist

Status: NOT_READY_FOR_PUBLICATION

- [ ] Final audio exists.
- [ ] Captions retimed from final audio.
- [ ] Thumbnail reviewed and approved.
- [ ] YouTube OAuth token exists locally.
- [ ] Authenticated channel verifies as Grok Archive Hub / @GrokArchiveHub.
- [ ] Upload script run only with explicit `--execute`.
- [ ] Upload privacy remains private by default.
- [ ] No automatic scheduling.
- [ ] No automatic public publishing.
- [ ] No automatic X post.
- [ ] Registry entry reviewed after upload but before public status change.
- [ ] Draft registry status changed only after all source fields are real.
- [ ] Public watch page generated only after valid YouTube ID, thumbnail, upload date, title, and description exist.
- [ ] X queue record created only through the existing explicit X workflow.
- [ ] Deployment approval obtained separately.
