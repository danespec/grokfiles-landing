# Rough-Cut Visual Style Guide

Status: rough-cut only. This is not a final motion-design package.

## Frame

- 1920x1080, 16:9.
- Warm off-white background.
- Dark ink text.
- GAH source cards use restrained amber accents.
- Unresolved-gap cards use a warning border but not sensational red-alert styling.

## Required Labels

- Opening frame: `ROUGH CUT — NOT FOR PUBLICATION`.
- Persistent top-right watermark: `ROUGH CUT — NOT FOR PUBLICATION`.
- Source posture cards:
  - `official Senate source material`
  - `official caption source`
  - `GAH hearing-exchange summary`
  - `human-audio-certified exact short quotation`
  - `editorial interpretation`

## Source Visuals

Every source visual must map to `asset-ledger.json` and `source-crop-ledger.json`.

Allowed:

- Cropping.
- Enlargement.
- Contrast adjustment.
- Highlight boxes.
- Arrows.
- Source labels.

Prohibited:

- Invented document text.
- Fabricated stamps.
- Fake classification markings.
- Removing relevant qualifiers.
- Altering quotation wording.
- Presenting an editorial recreation as a real document.
