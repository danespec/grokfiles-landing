# GAH-SHARE-043 — Correct dollar-amount social share DOM corruption

October 13, 2026, live DOM discovery. On /investigations/jpmorgan-nine-sars-epstein, Chrome at 390px measured body content 2431 CSS pixels past viewport, and at 1365px measured 4167px excess. Investigation confirmed the page social-sharing attributes contained unintended copies of article HTML. The source article's og:title properly contains '$1.28 Billion'; the derived share-card button's title was corrupted.

Root cause: Worker ensureV3DocumentShell substituted the dynamic socialShare HTML through String.replace with a replacement string built as $1 + dynamic socialShare + $2. Dollar patterns in the user-visible title, notably literal '$1.28', were interpreted by JavaScript as replacement capture $1. That embedded the entire article group into a share-button attribute and broke DOM structure. Other exact titles containing '$1M', '$158M', '$5.5M' etc may also be exposed; twelve static article/news titles contain a possible dollar-capture pattern in the current repository, not all confirmed broken.

Correction uses a function-valued replacement returning captured article content, dynamic share markup, and closing tag verbatim. Fallback insertion before closing main also uses a replacement callback, protecting other dollar replacement tokens such as $&. No changes to share destinations, original article content, article evidence, source PDF links, ad policy, Cloudflare Access, security, indexability, source datasets or payments.

Regression tests/test_social_share_dollar_043.mjs executes the actual ensureV3DocumentShell function in a controlled VM with representative share markup containing literal $1.28 and $&. It asserts literal title preserved, one original source paragraph/article/h1, one share section, correct nested placement, fallback behavior and reproduces old corruption as a test negative. Local all 43 Phase 0 suites passed. Independent GitHub CI, protected staging, original Pages bundle single Worker delta and live Chrome verification are required release gates.
