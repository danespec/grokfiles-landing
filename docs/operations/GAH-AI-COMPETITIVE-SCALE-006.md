## Staging-only prototype
Exact identifier control plus lexical overlap and 12-dimensional latent semantic analysis over 16 explicitly selected, already-published title/description pairs. This is statistical LSA, not neural embeddings or a corpus-wide search replacement. No title enrichment, training-permission changes, private source indexing or payment activation. Query runtime performs no network/origin/NAS calls; only its existing dedicated limiter is called. Current prototype covers a single reviewed exact identifier; other exact IDs abstain and clients should use existing public exact search.

Routes: /api/v1/research/search?q=..., /api/v1/publications/changes?cursor=0&limit=5&version=..., /.well-known/research-preview-openapi.json. Both GAH_STAGING=true and the protected staging Pages hostname are required; apex and production preview hosts return 404. Read-only methods, 256-character queries, 10-item pages, no-store/noindex, version conflicts, validators and fail-closed atomic throttles apply. Existing /openapi.json and /mcp expose the two preview interfaces only on staging. Production tool lists and schemas exclude them; existing production search remains unchanged.

Corpus: content/approved-public-metadata.json. All strings retained from published metadata; no underlying source text. Citation URLs identify discovery publications, not verification of every underlying claim. CI fails on any selected publication-byte change until the metadata model/feed is re-reviewed. Model build: scripts/build_research_preview.py uses build-time numpy/scikit-learn; no runtime AI service or vector database. Generated model is about 50 KB. Never ingest raw Intel or unreviewed Atlas drafts.

Feed: scripts/build_publication_feed.py produces deterministic sequence/version/hash records; corrected or withdrawn publications require a supplied reviewed reason and retain predecessor hashes. Initial feed has 16 records and no invented publication timestamps. Replays of identical input produce identical feeds. Persist previous snapshots; never silently reset the sequence on update. Runtime cursors require version pinning for repeatable reads. No automatic publication is performed.

Development smoke set: six known editorial targets retrieved at rank 1; unknown-ID and nonsense controls abstained. This small development set is not held-out citation-accuracy evidence. Evaluate a larger independently labeled set before promotion. Full existing search and metadata pilot cover different corpora; do not compare local computation time to network search latency as a speedup claim. Runtime cost increments and actual NAS workload require provider/host measurements; zero pilot NAS reads follows from code structure, not an account-wide observation.

Competitor checks must distinguish advertised features, public discoverability and actual labeled retrieval accuracy. Do not infer scores for inaccessible engines or copy competitor evidence claims. Title enrichment remains owner-gated.
