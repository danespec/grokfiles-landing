# GAH — Full-text search and private media-transcription queue

Date: November 20, 2026. Owner authorization: Expand genuine EFTA research discovery without arbitrary 120-page or 49,900-file ceilings.

## Existing search infrastructure (verified in the running NAS)

The Meilisearch indexes already existed: epstein_docs has 670,469 searchable OCR documents; efta_artifact_metadata_full has 835,022 file metadata records; efta_signal_context has 421,179 context records; and efta_high_signal_hits has 77,794 signal records. Do NOT rebuild them. The unified catalog includes 870,835 distinct EFTA identifiers; these distinct counts are not interchangeable, and none is the number of Google-indexed pages.

## Public ID-only keyword search

- POST /catalog/search (form body q=aviation) reuses the already deployed grok_ai_search proxy, with fast mode and AI summaries disabled.
- Exactly validated EFTA######## identifiers and catalog-derived format flags are the only upstream search fields allowed in returned HTML. No OCR text, private names, phone/address data, raw source paths, or upstream error details are displayed.
- Each hit links to a separate metadata-only exact-ID page. Only the existing 12,100 admissible published EFTA source pages can be followed beyond their metadata lookup. All other source restrictions remain in place.
- Search terms are submitted in the POST body rather than a GET query string, avoiding query-text disclosure in browser history, referrers and GA4 page URLs. Search results return noindex,follow, no-store, an explicit ad exclusion, restrictive CSP, and no-referrer. Existing wiki auth, rate limiting, analytics and source controls remain unchanged.
- A query returns up to 80 ranked matching identifiers; no claim of exhaustively listing all matches or independently adjudicating claims.
- /catalog embeds the keyword-search form. /catalog/media exposes links to 151 media identifiers (without playback, transcripts or previews). The main homepage links to the wiki keyword-search entry.
- The wiki editorial sitemap remains 89 entries, the qualified EFTA source sitemap remains 12,100, and individual search-query pages are NOT in either sitemap.

## Media audit and private transcription queue

A NAS-local ffmpeg probe covered 301 physical source files across All Data and Data 8, corresponding to 151 distinct video/audio EFTA identifiers (147 video, 4 audio). There are 146 representative recordings with audio tracks, approximately 140 hours once duplicate holdings by identifier and media class are consolidated. Five video-bearing source IDs had no detected audio track. Some audio tracks may have no speech.

- The private queue contains 146 audio-bearing EFTA identifiers, source paths, duration and provenance-review status.
- It is stored only under the authorized NAS user's restricted directory with mode 600, never in GitHub or the wiki static files.
- The reproducible transcription worker requires an explicitly supplied preinstalled local faster_whisper model and refuses to download a cloud model. The environment has no model or package installed, so no transcripts were generated by this release.
- Any future transcript is private and unreviewed. Publishing it requires source-verification and identity/privacy controls; a file existing in an archive does not establish anything about an allegation.
- 76,932 visual references across 53,017 EFTA IDs remain in the separate visual index. They are not a verified count of unique photographs.

## OCR admission review is a separate gate

A full OCR sampling/safety scan previously screened 667,438 conventionally named OCR identifiers: 134,346 passed the displayed-excerpt gate, 126,698 the longer 64 KB screen, and 116,285 are newly eligible review candidates. These are not automatically cleared for publication. Another 1,687 previously admitted pages require review for markers outside their public excerpt. Neither count changes in this keyword-search release.

Empty/invalid queries, XSS, HEAD, POST denial, upstream error handling and noindex are tested.
