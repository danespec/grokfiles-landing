## Verified defects
Existing publicSearchRowRelevant accepts one token for a two-token query. Editorial rows are concatenated before backend hits, deduplicated and sliced without relevance scoring. Generic Epstein overlap therefore admits unrelated navigation results, as shown in the supplied original ten. Existing identifier normalization/policy remains untouched on production. The old 006 metadata regex also truncated descriptions at apostrophes; 007 derives exact original title/description attributes with an HTML parser and tracks those extraction corrections in the feed without editing any publication.
