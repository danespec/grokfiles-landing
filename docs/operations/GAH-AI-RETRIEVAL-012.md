# GAH-012 — filtered editorial passage retrieval (protected experiment)
Base: reconciled with production merge a04e6ba (PR #284), deployment d22e7ebd-614b-4ac5-92c2-2cabbce8a197.
The publisher authorized deeper retrieval. This phase uses the same 104 eligible canonical publications, hash-bound to existing source HTML. A deterministic local extraction reads visible main-content blocks and omits script, navigation, hidden/raw/quoted material and sensitive blocks matching conservative privacy rules. It does not index source PDFs, private Intel, raw NAS records, or unreviewed publications. It stores term postings, not passage strings. This is **filtered editorial passage coverage**, not complete article-body coverage, neural embeddings, or full-archive semantics. Mechanical exclusions are not proof that all personal information is absent.
The 012 candidate combines metadata retrieval with passage BM25, weighted query coverage, subject anchors, bounded reranking and conservative abstention. Existing 011 API remains unchanged in ranking behavior; exact identifier and recognized navigation controls use the existing path. New search is restricted to the exact protected 012 staging alias, with fail-closed limiter, noindex/nofollow and no AI discovery advertising. No generated answers or additional NAS/origin reads. No production activation.
## Privacy and public repository
The repository is PUBLIC. The generated passage index must **not be pushed** to it. Keep the complete candidate and its index in the local worktree and protected staging only. The source-only build now requires GAH_PRIVATE_PASSAGE_INDEX outside the checkout. A Node loader supplies this ephemeral input to tests and an esbuild resolver supplies it to a private Worker bundle. CI generates the input in RUNNER_TEMP and uploads no derived artifact. Before promotion, independently review the expanded retrieval scope; verify every indexed input is appropriate for this expanded retrieval scope. Do not treat the existing metadata admission rule as blanket approval for protected identities. No independent privacy or relevance attestations have been manufactured.
## Results and gates
104/104 publications have eligible passages; 6,363 passages, 68,444 tokens, 716 excluded sensitive blocks. Existing source corpus hashes unchanged. Ten selected known-item controls passed; these are development controls, not independently adjudicated holdout judgments. Frozen 250-query local comparison: 250/250 executed, no errors, no generated answers or external reads; 20/20 privacy challenges abstained versus 11/20 in 011. Candidate abstained 81 times versus 42 in baseline. Corrections abstentions 10/20 versus 1/20; some baseline matches were irrelevant to Atlas status, revision or withdrawal questions, but quality must be independently reviewed. First destination changed on 85 queries. Do not infer broad accuracy from execution success. Local wall time is not Cloudflare CPU. Preserve all existing production behavior until protected evaluation, independent relevance judgments, privacy checks, resource measurement and actual operational validation pass. Further work: route publication/Atlas administrative questions to the existing versioned interfaces, evaluate correction recall and secondary-result precision; compare lexical and neural reranking on a separate holdout before deciding whether neural embeddings merit cost. No payment, training, Access, WAF or ads changes.

The new 20 author-selected paraphrase controls were frozen before execution. Current metadata top1/top3/top10 = 16/18/18; passage = 15/15/15; neural reranking of existing passage candidates = 15/15/15. Dense metadata alone = 16/18/20. Exploratory three-lane reciprocal-rank fusion = 19/19/20. This fixture is now development evidence, not independent holdout certification. A broader frozen 250-query diagnostic initially found that candidate expansion reintroduced five privacy challenges and six unanswerable queries. Shared guard changes preserved all 20 privacy abstentions and 22/25 unanswerable abstentions, with 9/20 identifier abstentions matching the original baseline. The three remaining unanswerable cases and broad secondary relevance require review; do not interpret abstention counts as quality labels. Administrative navigation now points to existing correction, methodology, investigation, publication-feed, API and Atlas status resources. No fabricated Atlas findings. Dense expansion is **offline only**, not part of the staged or public API.
