# GAH-AI-RETRIEVAL-011 — publisher-authorized editorial research
## Standing publication rule
Owner authorization 2026-11-14: eligible published editorial material is automatically included with each normal publication build. No separate per-publication semantic admission approval is required. This does not attest independent human relevance judgments.
- Stage new or corrected public editorial assets and the existing canonical sitemap publication registration before running `deploy/prepare-publication-release.sh`.
- The script automatically rebuilds the index when the tracked, canonical, sitemap-registered editorial inputs change. It refreshes the runtime fingerprint and runs public research contract tests. It does not publish or alter security settings. Set GAH_RESEARCH_PYTHON to the existing pinned environment; see scripts/requirements-retrieval-010.txt.
- Commit generated corpus/runtime with the publication, and include the indexed static assets in the release artifact. CI rejects stale inputs, changed hashes, or invalid model dimensions; future publishing must use this build step. No background crawler, external embedding service, or automatic deployment bypass.
- Index metadata only from eligible editorial routes, including News Desk, primary research articles and substantive methodology. Exclude drafts, private Intel, raw source records, receipt readers, untracked files, noindex and noncanonical pages. Corrections replace old metadata; removed/nonindexable pages are revoked on rebuild. The previously approved bounded passage survives only with its original file hash.
- Mechanical checks reject obvious private identifiers and filesystem paths. The existing editorial publishing/redaction policy remains the privacy boundary, not automated inference of new identities.
## Public surface
GET/HEAD /api/v1/research/editorial-search, /api/v1/research/editorial-corpus (versioned pagination). MCP search_editorial_research; OpenAPI, llms and existing agent catalog advertise the interface.

The complete archive remains accessible through existing /api/search and identifier routes. The old experimental endpoint remains protected. GAH_PUBLIC_RESEARCH_ENABLED=false disables only the new public surface. Required limiter fails closed; public 30/minute scope; no-store, noindex API responses, ai-train=no.
