# Next semantic phases — release boundaries

## 013 — guarded neural hybrid
Compare three-lane lexical/metadata/dense retrieval on newly frozen, independently graded query families. Keep the exact/administrative/privacy routes ahead of candidate expansion. Evaluate recall, top-three precision, MRR, nDCG and abstention on independently labeled pools; retain the existing public model as a fallback. Treat the 20 paraphrases and 250 existing diagnostics as development controls, not new holdout evidence. Current offline dense configuration is exploratory. No external inference service, purchase, public vector export or training-policy change without authorization. Benchmark cold/warm runtime CPU, memory, latency and rate-limit behavior before choosing a serving architecture. Do not bundle local ONNX weights into Pages without resource measurements.

## 014 — verified archive semantic retrieval
Full-archive semantics must use a separately reviewed public-source manifest, not blanket NAS access. Each candidate source needs an approved public locator, exact source fingerprint, release status, edition, page/offset mapping, redaction status, and provenance. Exclude private/restricted/unreviewed, quarantined, non-public or unreadable records; do not reverse redactions or infer protected identities. The 011 automatic editorial-admission rule remains in force for eligible editorial pages; it is not blanket authority to expose raw archive material. Start with a small eligible source sample. Index only explicitly eligible redacted public text, maintain private versioned derived indexes, bind every returned result to its approved public locator and original hash. Preserve exact identifier search and withdraw invalidated sources from all derived indexes. No public full-text or vector dump. Test unknown IDs, withheld pages, duplicates, withdrawn records and no-source cases; report the number admitted and the denominator before claiming archive-wide coverage.

## 015 — citation-grounded answers
Start with an evidence packet (existing canonical editorial locators, source hashes, reviewed citation memberships, and explicit scope). Later add verified passage spans and primary-source references. The answer layer must separate source-reported statements from independently established facts, allegations from adjudication, association from culpability, and proposals from executed events. Require claim-to-source linkage, source-version checks, abstention when citations do not entail the requested conclusion, and conflict/uncertainty labels. No unsupported synthesized conclusions or identity inference. Independent claim and citation-entailment review is mandatory before enabling generated answers. Ingestion, retrieval and answer controls are separate release gates.

## Verified archive-source invalidation gate
Private archive index releases run deploy/prepare-archive-retrieval-release.sh with external GAH_ARCHIVE_EVIDENCE and GAH_ARCHIVE_SOURCE_OBSERVATIONS paths. A verified PDF-byte change bound to a prior audit automatically revokes its parent and all child locator mappings. Revocation is sticky; changed sources never gain admission. Unknown candidates, failed/non-PDF responses and mirror holds cannot create eligibility. Invalid provenance or inconsistent receipts stop the release. All ledger writers share an exclusive evidence lock; locator reads revalidate current state before returning a result. This consumes an observation batch; it does not claim a scheduled remote source monitor exists.

## Private neural serving
scripts/serve_neural_013.mjs loads the existing pinned cached model with network and remote inference disabled. The HTTP service binds only to loopback; it provides JSON research responses with no source text or vector export, no raw query logs, bounded request size, two active searches, a bounded short-lived cache and a request limiter. This is private serving, not a public production deployment or independent relevance certification. Explicit Barak/Leon Black subjects bind all fused candidates to published metadata. Passage and neural citation packets are rebuilt from final ranked results and tied to their response versions.

## Source-bound generation proposals
The private evidence-candidates-015 module accepts only current approved publication descriptions with their build fingerprints. It rejects restricted questions, altered/foreign sources, invalid model schemas, truncated/tool-call responses and changed quotations. Model-generated selections are proposals: every quotation must equal the entire supplied description, and no public answer or review approval is produced. A real Workers AI Granite test selected two public summaries; both passed source-fidelity checks. That experiment used 2.505 neurons from the observed free allocation; no paid infrastructure was purchased. It does not replace independent relevance/privacy/entailment evaluation.

## Practical release criteria (owner revised)
Absolute p95 gates supersede the old baseline-relative gate: exact IDs 1 second; editorial retrieval 2 seconds; advanced semantic retrieval 3 seconds; reviewed citation-grounded answers 15 seconds. Preserve reliability and source safety. A slower successful search within these budgets does not trigger rollback.

The existing search_editorial_research MCP tool and editorial-search HTTP route now accept strategy=metadata|passage|hybrid. Metadata remains the default; full-archive search is unchanged. The Ask GAH publication-research action uses hybrid mode and renders source candidates, never an unreviewed generated conclusion. Feature flags GAH_PASSAGE_ENABLED, GAH_NEURAL_ENABLED and GAH_EXACT_CACHE_ENABLED are independently disableable. The 30-second exact cache admits only sanitized verified exact-ID responses and remains behind existing throttles.

Public neural serving uses precomputed private 384-dimensional BGE metadata vectors and a Workers AI binding for query embeddings. The pinned local MiniLM remains available for private research; its vectors are never mixed with BGE. A canary detects an inconsistent provider snapshot. Two concurrent encodes per isolate, coalescing, bounded version-aware cache, a 1.5-second encoder deadline and account-wide budgets (30/minute, 5,000/day) protect resources. Encoder failures/budget exhaustion fall back to passage ranking. No NAS documents or derived index dumps are published. Vector snapshots rebuild incrementally by publication fingerprint through scripts/build_editorial_vectors_013.py; releases with stale vectors fail the gate.

GAH-014 remains limited to seven previously verified locator records from the 69-dossier sample. Existing source observations, revocations and privacy holds are retained; no DOJ access is required to operate those admitted sources. Unresolved sources cannot be admitted by changing the latency policy.

GAH-015 serving accepts only current public descriptions with independent, packet-bound privacy and evidence approval. scripts/prepare_answer_review_015.mjs prepares unapproved packets from real model selections; scripts/build_reviewed_answer_bank_015.mjs rejects invalid approvals, changed sources or non-verbatim descriptions. answer=reviewed returns an approved extraction only if a matching current packet exists; otherwise it explicitly abstains. No reviewer approval is generated automatically. A zero-entry bank is an honest review dependency, not a completed generative-answer feature. GAH_REVIEWED_ANSWERS_ENABLED independently disables this path.

Build advanced server artifacts outside the checkout using --advanced and external GAH_PRIVATE_PASSAGE_INDEX, GAH_PRIVATE_EDITORIAL_VECTORS and GAH_PRIVATE_REVIEWED_ANSWERS. Include only the compiled Worker in the deployment; never copy private inputs into static assets or Git. Standard --production builds still physically omit advanced retrieval and remain a rollback option. deploy/prepare-publication-release.sh --check stays mandatory; supplying GAH_PRIVATE_EDITORIAL_VECTORS adds its freshness gate. Independent relevance metrics remain unverified until real judgments are supplied; do not remove beta or claim superiority from development controls.

Actual provider consistency testing found batch-dependent BGE outputs (same canary: single-repeat cosine 1.0, single-versus-32 cosine 0.9843). Private index generation and request-time query/canary encoding therefore use single-item requests. Rebuild old batched snapshots; do not weaken the snapshot canary to accept incompatible embeddings.
