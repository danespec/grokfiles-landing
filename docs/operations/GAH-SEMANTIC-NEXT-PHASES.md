# Next semantic phases — release boundaries

## 013 — guarded neural hybrid
Compare three-lane lexical/metadata/dense retrieval on newly frozen, independently graded query families. Keep the exact/administrative/privacy routes ahead of candidate expansion. Evaluate recall, top-three precision, MRR, nDCG and abstention on independently labeled pools; retain the existing public model as a fallback. Treat the 20 paraphrases and 250 existing diagnostics as development controls, not new holdout evidence. Current offline dense configuration is exploratory. No external inference service, purchase, public vector export or training-policy change without authorization. Benchmark cold/warm runtime CPU, memory, latency and rate-limit behavior before choosing a serving architecture. Do not bundle local ONNX weights into Pages without resource measurements.

## 014 — verified archive semantic retrieval
Full-archive semantics must use a separately reviewed public-source manifest, not blanket NAS access. Each candidate source needs an approved public locator, exact source fingerprint, release status, edition, page/offset mapping, redaction status, and provenance. Exclude private/restricted/unreviewed, quarantined, non-public or unreadable records; do not reverse redactions or infer protected identities. The 011 automatic editorial-admission rule remains in force for eligible editorial pages; it is not blanket authority to expose raw archive material. Start with a small eligible source sample. Index only explicitly eligible redacted public text, maintain private versioned derived indexes, bind every returned result to its approved public locator and original hash. Preserve exact identifier search and withdraw invalidated sources from all derived indexes. No public full-text or vector dump. Test unknown IDs, withheld pages, duplicates, withdrawn records and no-source cases; report the number admitted and the denominator before claiming archive-wide coverage.

## 015 — citation-grounded answers
Start with an evidence packet (existing canonical editorial locators, source hashes, reviewed citation memberships, and explicit scope). Later add verified passage spans and primary-source references. The answer layer must separate source-reported statements from independently established facts, allegations from adjudication, association from culpability, and proposals from executed events. Require claim-to-source linkage, source-version checks, abstention when citations do not entail the requested conclusion, and conflict/uncertainty labels. No unsupported synthesized conclusions or identity inference. Independent claim and citation-entailment review is mandatory before enabling generated answers. Ingestion, retrieval and answer controls are separate release gates.

## Acceptance and rollback
Keep GAH-011 operational. Promote only a validated candidate with exact artifact identity, source/hash and privacy invariants, independent relevance results, real limiter checks, resource budgets, compatible archive and Atlas behavior, and authenticated staging evidence. Release by narrow feature flag with rollback. No changes to Access, WAF, redactions, payment or ai-train policy.
