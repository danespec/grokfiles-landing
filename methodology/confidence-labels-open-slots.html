Confidence Labels and Open Receipt Slots

Confidence labels describe review posture. Open receipt slots preserve unresolved checks so they are not silently converted into conclusions.

Back to MethodologyOpen Receipt SlotsLive changelog

What this can show

L1 — Source Found

A record exists and is linked.

L2 — Context Supported

The record has enough surrounding context to explain why it matters.

L3 — Review Lead

The record raises a structured question but does not prove the answer.

L4 — Source-Locked Finding

Multiple durable sources support a narrow factual finding.

Open Receipt Slot

A missing, unresolved, ambiguous, degraded, or pending source item.

What this does not prove

  • A confidence label does not describe guilt, intent, agency, or liability.
  • A review lead is not a finding.
  • An open receipt slot is not proof.
  • Missing context does not become evidence by itself.
  • Public proof remains open; membership or Reading Room support does not buy hidden evidence.

How Grok Archive Hub uses this

The archive uses labels to keep source posture visible. If a source check is unresolved, it stays open. If a claim is not source-locked, it should remain a question, queue item, or caveated review lead.
