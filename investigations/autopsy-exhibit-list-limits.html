The Autopsy Exhibit-List Pointer Has a Narrow Job

EFTA00039356 is useful because it shows an autopsy-report pointer. It is not the autopsy report itself and should not be written as if it contains medical findings.

By Grok Archive Hub Editorial Desk · Published 2026-07-12 · Updated 2026-10-01

Open source chain All investigations Explore the Archive

Thesis

EFTA00039356 is useful because it shows an autopsy-report pointer. It is not the autopsy report itself and should not be written as if it contains medical findings.

The exhibit-list source card is a good example of why a document autopsy matters. A pointer can be real evidence while still being weak evidence for the thing readers most want to know. The archive can say that a pointer exists and link the render. It cannot promote medical conclusions from a pointer alone.
