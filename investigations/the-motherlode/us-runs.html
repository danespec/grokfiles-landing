U.S. Investigations: RUN 1–15

A fifteen-run chain that moved from network hypotheses to source-locked corporate, banking, and transaction reconstruction.

Grok Archive Hub Editorial Desk · October 1, 2026

Fifteen-run surgical series. RUN 1–15 progressively tested U.S. corporate, technology, public-safety, investment, banking, and transaction links. The value of the series is not only what it found; it also records where proposed bridges failed, where ownership or funding remained unresolved, and where bank records strengthened a claim.

Recovered run map

  1. RUN 1 — Barak/U.S. nodes. Baseline U.S. legal/financial and Reporty/Carbyne/NG911 access questions; the recovered graph explicitly rejected a broader A–B technical bridge.
  2. RUN 2 — Carbyne / NG911. U.S. public-safety access and commercialization lane.
  3. RUN 3 — Ridge / Chertoff. Tested homeland-security adviser continuity. The recovered graph treats the Ridge and Chertoff episodes independently and does not establish an improper-influence chain.
  4. RUN 4 — Intrater / Renova. Reconstructed the documented Reporty introduction while keeping the 2017 A-1 legal holder and source of funds unresolved.
  5. RUN 5 — 2017 A-1 closing gap. Bounded search for the missing closing instrument, holder, and funding proof.
  6. RUN 6 — Levitection / BIRD / DHS. Tested financing and government-program adjacency without equating a proposal or term sheet with a funded close.
  7. RUN 7 — Epstein technology-banking bridge. Shifted the investigation toward bank execution rather than name proximity.
  8. RUN 8 — Southern Trust ledger. Reconstructed Southern Trust investment activity and separated confirmed wires from incomplete ledger coverage.
  9. RUN 9 — AdFin / Valar. Company-level and fund-level capital routes were separated rather than collapsed into one theory.
  10. RUN 10 — Honeycomb / Butterfly. Tested investment-vehicle and trust crossover while retaining negative-control results.
  11. RUN 11 — Financial machinery. Focused on entity, account, administrator, and transaction mechanics.
  12. RUN 12 — All-bank technology discovery. Applied a BANK-0 through BANK-5 evidence scale across the recovered technology-investment graph.
  13. RUN 13 — Environmental Solutions Worldwide. Built the 2005–2012 ESW lifecycle from issuer records, bank settlement, ownership records, and the later BFP exit.
  14. RUN 14 — Black Family Partners three-asset package. Reconstructed the ESWW / AP SHL / AP Technology sale package and its closing evidence.
  15. RUN 15 — Forensic accounting. Followed the repricing, allocation changes, settlement amount, and remaining buyer-side / execution-document gaps.

Provenance pattern

Later U.S. runs preserve a consistent artifact family: a narrative MASTER.md, normalized EVIDENCE.csv, graph or structured JSON, and a SHA-256 manifest. Those files document the research process. Public claims still require the underlying EFTA, bank, SEC, court, government, or other cited source.

Negative findings stay visible. A missing technical bridge, unknown legal holder, absent bank settlement, or unlocated closing document is not silently converted into a positive claim. Those gaps are part of the result.
