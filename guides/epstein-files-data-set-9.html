What is Data Set 9?

Data Set 9 is one of twelve numbered publication groups in the DOJ Epstein Library. The DOJ disclosure portal also maintains separate collections for court records, FOIA materials and earlier releases. A data-set label identifies where a file was published; it is not a chronology, list of offenders or proof of a particular claim.

When checked on November 17, 2026, the official DS9 index begins with EFTA00039025.pdf and lists additional PDFs on successive pages. The first visible page includes EFTA00039356.pdf, EFTA00039416.pdf and EFTA00039660.pdf. These are examples of listed files, not a statement of the complete identifier range or a count of all available documents.

How to find and download a Data Set 9 PDF

  1. Open the official index. Browse its paginated list. For a known identifier, try the full-library search before manually paging through results.
  2. Preserve the exact identifier. Keep EFTA plus eight digits, including leading zeros. A search for a partial number can return unrelated records.
  3. Open the linked file. Use the DOJ-provided link, complete any official age-verification requirement and save the PDF if appropriate. The index itself is not a ZIP download. A missing file should be reported as unavailable, not reconstructed from an assumed URL.
  4. Record the source. Save the exact official URL, page reference and access date. If comparing copies, record a SHA-256 hash of each obtained file. A hash identifies bytes; it does not prove that assertions inside a document are true.
  5. Read the context. Identify the author, recipient, date, record type, and relevant surrounding pages. Compare independent records before drawing conclusions.

Why a Bates number is not always a standalone PDF

Identifiers can refer to pages inside a larger file. GAH's existing source notes for EFTA00153570 and EFTA00153571 point to pages two and three of the parent PDF EFTA00153569. Do not assume that every number has its own downloadable file. Preserve both the page identifier and parent-file identifier when citing an interior page.

For a source identified through a third-party mirror, compare the original and mirror only when the exact bytes are available. GAH's EFTA00704168 source note identifies a reviewed mirror and its hash without claiming a fresh DOJ byte match. A mirror is not automatically equivalent to the official record.

Search limitations and citation checklist

DOJ's search page cautions that handwritten and other difficult-to-process records may not be reliably searchable. Search variants, inspect the actual page and check the parent document. A zero-result search is not evidence that a person or event is absent from the full collection.

For each claim, record the EFTA ID, file or exhibit title, date, page, source URL, what the record directly supports and what remains unconfirmed. Names in correspondence, address books or schedules do not establish misconduct. Report potential privacy problems through the DOJ's disclosure notice or GAH's corrections process.
