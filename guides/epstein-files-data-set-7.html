File starts and interior Bates pages

Locate the actual parent PDF and verify its internal Bates labels instead of constructing a URL for every intervening number.

Worked example: why a hundred-number Bates gap is not a hundred files

The observed Data Set 7 directory returned 17 visible file links without numbered pagination. The first two displayed starts are EFTA00009016 and EFTA00009116—an arithmetic separation of 100. It would be incorrect to report that 99 files are missing, or that 100 independent records exist between the starts, based on that comparison alone.

A file-start label can represent a multi-page parent PDF. To cite an interior Bates number, locate the parent file shown in the official index, open that PDF, read its printed or embedded page labels, and verify the precise page where the cited information appears. If the parent cannot be established, mark the reference unverified rather than attributing a claim to an inferred document. This guide's observed count concerns only the returned index view; neither its completeness nor the content of underlying files was independently established here.

Find and cite a file from Data Set 7

  1. Locate the exact filename. Begin at the official index, or search the library for the complete EFTA number including leading zeros.
  2. Confirm the parent document. Open the official listed file when available. Follow the DOJ's own access requirements; do not invent a direct PDF URL for an unlisted number.
  3. Record provenance. Save the data-set label, filename, actual page, source URL and access date. A file hash can identify a copy but cannot authenticate assertions made inside it.
  4. Limit the conclusion. Compare what the record directly states against corroboration and competing explanations. Preserve redactions and report any inadvertently exposed personal information through the DOJ's published notice.
