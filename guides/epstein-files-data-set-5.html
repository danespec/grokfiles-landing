Worked example: matching an early filename against a three-page index

The observed Data Set 5 first page runs consecutively from EFTA00008409 to EFTA00008457. A researcher looking up EFTA00008409 should verify that exact eight-digit string on the original DOJ index before opening its listed file; a different file start later in the displayed sequence is a separate locator, not proof of an independent document or event.

The index presents a three-page navigation control, unlike Data Set 2's longer index. That shorter control is a property of the listing, not an independently established total number of PDF pages or file contents. The final page was not independently fetched for this guide. When assembling a source note, distinguish (1) the listed file start, (2) the actual parent PDF that opens, and (3) the specific page within that PDF. An internal Bates label may differ from the filename used to enter the document. Do not infer the content or completeness of unreviewed files.

Find and cite a file from Data Set 5

  1. Locate the exact filename. Begin at the official index, or search the library for the complete EFTA number including leading zeros.
  2. Confirm the parent document. Open the official listed file when available. Follow the DOJ's own access requirements; do not invent a direct PDF URL for an unlisted number.
  3. Record provenance. Save the data-set label, filename, actual page, source URL and access date. A file hash can identify a copy but cannot authenticate assertions made inside it.
  4. Limit the conclusion. Compare what the record directly states against corroboration and competing explanations. Preserve redactions and report any inadvertently exposed personal information through the DOJ's published notice.
