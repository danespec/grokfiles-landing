Nonconsecutive file identifiers

The first page jumps from EFTA00003380 to EFTA00003434, then lists EFTA00003435 through EFTA00003441 before jumping to EFTA00003858. These are visible file starts, not a count of missing pages. A Bates identifier between two listed starts may be inside a longer file, or may not be present; the listing alone cannot establish which. Inspect the relevant file’s own page numbering before citing an interior number.

Research coverage

This page is an index-navigation guide only. GAH’s published identifier register does not yet contain a dedicated dossier assigned to this data set. No new findings about the underlying records are asserted. Use the identifier register and Story Atlas to find published context; an absent search result is not evidence that a record is absent from the DOJ collection.

Find and cite a file from Data Set 3

  1. Locate the exact filename. Begin at the official index, or search the library for the complete EFTA number including leading zeros.
  2. Confirm the parent document. Open the official listed file when available. Follow the DOJ's own access requirements; do not invent a direct PDF URL for an unlisted number.
  3. Record provenance. Save the data-set label, filename, actual page, source URL and access date. A file hash can identify a copy but cannot authenticate assertions made inside it.
  4. Limit the conclusion. Compare what the record directly states against corroboration and competing explanations. Preserve redactions and report any inadvertently exposed personal information through the DOJ's published notice.
